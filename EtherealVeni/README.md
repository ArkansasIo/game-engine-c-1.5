# Ethereal Veni Runtime

This directory contains the standalone .NET runtime architecture for **Ethereal Veni** and the **Ethereo Pandora** game.

## Projects

- `Engine/` — engine runtime and reusable systems.
- `Server/` — server-authoritative multiplayer host and HTTP control surface.
- `Editor/` — editor host and tooling entry point.
- `Game/` — Ethereo Pandora executable/game layer.

All platform-specific console SDKs remain external dependencies and are not committed to this public repository.
